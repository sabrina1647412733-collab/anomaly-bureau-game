# 背包界面重设计验收

根据用户确认的参考图，在原Godot工程上替换随身背包视图。使用炭灰底、细线、暖纸色文字和黄铜色选中状态；沿用现有物品所有权、持物与存档系统。

## 实际改动

- 分类只有「道具、线索、钥匙、衣物」，没有「全部」。每次打开默认道具，点击或Tab切换时实际过滤；分类内记住选中物品，各类显示当前数量。
- 六列四行方格，空格轻边框；超过24件时自动增加行数并滚动。方向键选择物品，选中有边框和角标，鼠标悬停可看完整名称。
- 右侧大图、类别、物品名、可滚动完整说明和独立取出按钮；长文不会把按钮挤走。E取出、B收纳/打开、Esc关闭沿用原操作，右上角可点击关闭。
- 17张640px透明道具图替代原通用线条图标。毛衣、布鞋使用现有模型渲染；纸件、手机、座钟、钥匙为原创程序美术；家庭照片为本轮生成的虚构旧照，父亲和孩子的照片脸部受损遵守剧本。来源及完整生成提示词见 `assets/ui/inventory/ART_SOURCES.md`。
- 空分类清空旧详情并禁止取出；不会把此前分类中的物品误拿出来。分类不更改物品顺序/所有权，不增加剧情门槛，不改变存档格式；原衣交还记录归线索。
- 界面按可视区域整体居中缩放，检查1280×720、1600×900、1920×1080；游戏继续使用原项目的canvas_items缩放策略。
