# 第一案美术与声音精修

本轮在同一Godot工程上更新，第一案仍是三个夜班与唯一结局。街道的四个原始模型、地点数据、建筑名和功能没有替换；周小满事故后去向未明的设定不变。

## 实际改动

洗衣楼八个区域使用保留原结构的倒角视觉模块，原碰撞壳体保留。新增洗衣机控制面板、门圈、胶圈、铰链、脚座与排水软管，独立滚筒可继续旋转。长椅、门和检修桌有独立可编辑模型。白模仍保留，新增源位于source_art，细节接口位于laundry_finish.gd。

一楼电视与信箱、二楼柜台与工作终端、三楼床品与衣柜、五楼玩具机、屋顶和地下材质补足。新抽屉的正面朝向房内，实际站位可以瞄准最低层抽屉；照片有相框支撑。床垫补充碰撞，避免跳上床后脚部陷入新增表面。所有楼层照明保留通行可见度。

修正角色的双臂后折问题。作者工具根据网格空间变形和原Godot静止骨架转换轨道，不直接复制骨轴不同的节点旋转。周秀兰坐姿经多时刻、侧面检查；阿七移到实际长椅上。衣袋离场后不再每帧错误重置局部坐标。原角色网格与纹理不覆盖。

手持界面的专用补光降低，肤色、袖口与手掌过渡调整；拾取反馈改到左下角，避免挡住手机。材质和灯光提升属于本轮，角色仍采用现有纹理和基础动作，尚未制作完整面部表情与口型。

声音包括一首署名授权配乐、四段程序创作氛围配乐、雨声、真实洗衣机运转与机门声、敲门，以及程序拟音脚步等。出租屋、调查、地下、数衣和认领阶段切换配乐并淡化衔接；人物对白会压低音乐。手机仍从房东催租开始，接受信封后才收到派遣信息。音乐、音效、对白、环境总线可分别调整。音频来源、处理说明与许可在assets/audio/finish。

## 画面与发行

使用实际Godot渲染检查店堂、七号机、柜台长椅、门厅、303、402、503、屋顶、B1、出租屋、五类手持物、混音设置与鸣谢。额外采样四个坐姿时刻和侧面。Vulkan与OpenGL兼容模式均已生成画面；本地截图在_预览/20261022_美术声音，未加入Git。

Windows v0.3.2安装包和免安装包沿用原发行入口，增加声音署名与许可证。源码仍从project.godot打开。详细发行校验值随Release的SHA256SUMS.txt发布。

自动回归与画面对照不能替代玩家完整主观试玩、不同显卡实测或戴耳机的混音评价。本轮没有把合成配音和基础角色动作表述为真人表演，也没有保证所有未知缺陷都已经消除。

发行PCK使用包外验收驱动读取，三夜60项与声音/姿态45项全部通过；这些重复项不再累加进341项。原生Windows程序在Vulkan（Forward+）和OpenGL兼容模式下启动并按帧数退出，返回码均为0。本次原生发行程序未执行包外测试脚本，故流程验证使用同版本Godot读取实际PCK，未借用源码资源目录。

安装验证：默认LocalAppData目录安装成功，安装后PCK与发行PCK的SHA256一致，实际安装目录中的游戏启动成功，静默卸载返回0且测试程序与注册项均清除。声音署名与对应许可文件随安装落盘。另测本机F盘工具目录时，原位卸载器在初始化前退出1且未生成日志；把同一卸载器及数据移到C盘测试目录后成功清理，未更改系统防护设置。默认安装路径的完整安装/卸载已单独通过，F盘工具目录问题记录为本机路径问题，根因未确认，未声称所有自定义路径都已验证。

发行前最后核对修正背包底部的旧操作说明：F查看手中物品，B收纳或打开背包。信封反馈同样明确先取出再按F重读，重新构建交付包。
