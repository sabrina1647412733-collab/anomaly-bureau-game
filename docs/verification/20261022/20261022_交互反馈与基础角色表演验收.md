# 交互反馈与基础角色表演（2026-10-22）

本轮在现有工程继续更新，只同步GitHub源码，不重新生成安装包或ZIP。打开本工程 `project.godot`，资源导入后F5体验；Release v0.3.2的旧二进制不含本轮内容。

## 交互反馈

门锁、抽屉、信箱、检修盒、电梯、排水设备、检修梯等操作失败时，在左下角给出目标、具体原因和下一步，并配短促锁舌或设备阻止音，中心准星短暂变色。反馈不覆盖剧情字幕，也不强制打开阅读页。重复交互有音效冷却，避免连响。

区分后房外门、303抽屉、503信箱、503检修盒与七号机的钥匙用途。正确钥匙在包里仍自动使用；没有强制玩家先手持指定钥匙。503从内反锁时明确经502维修通道进入，401和故障电梯明确说明无需继续尝试。

修正了两个重复操作问题：排水泵已经通电后再次送电不再错误复位；排水完成后重开阀门或切电盘不会再次降低水位或破坏安全状态。

## 声音与角色

重新制作30句现场合成对白，按角色配置语速、音高、音量与句内停顿。字幕正文来自当前剧情。周秀兰的迟疑与释然、老周的停顿和许砚的问句采用不同配置。句间等待改为独立间隔，不再在完整录音之后按字数额外等待数秒。

三位NPC周秀兰、老周、阿七新增基础嘴部开合、眨眼、忧虑与释然形变，以及轻微头部叠加动作。嘴部按实际录音的响度包络与播放位置驱动，静音时闭口；跳句、停止、暂停、返回菜单不会继续说话或留在张嘴状态。身体动作和座高继续使用上轮修正结果。

这是基础表演：没有逐音素唇形、舌部动画或真人情感配音，许砚本轮没有新增面部形变。原模型的三角轮廓与贴图限制仍存在，不能把本轮结果当作电影级表情。
