# 暂停、交互与脱困修复（2026-10-22）

本轮是 v0.3.2 之后的源码小更新。在现有 Godot 工程按 F5 游玩；按用户要求，不重做安装包或 ZIP，GitHub Release v0.3.2 的旧二进制不包含本轮修复。

## 修复结果

- 人物对话中 Esc 打开暂停菜单，不再跳过一句。暂停期间，继续按钮和对白按键不提交下一句或剧情回调；恢复游戏后继续原句。
- 返回主菜单会取消未完成对话，不再让后台对白结束后把游戏状态改回现场。重新交谈仍可完成相应剧情。
- 手机、背包、阅读、时钟、暂停和主菜单阻断现场快捷键，避免 V 切换视角或 E 使用残留交互目标。
- 暂停真正冻结人物物理，下落、速度和坐姿处理不再在暂停期间继续；继续游戏、读档及脱困恢复物理。
- 坐下后脱困会重新启用人物碰撞、还原站立胶囊并恢复鼠标控制，避免回到入口后再次穿地。
- 对话暂停菜单支持生成手动存档。存档恢复到对话前的现场，不提前执行授予物品或推进剧情的回调；未完成的对话可重新触发。暂停后直接继续则保留当前句子。
- 任务短信横幅在对话、阅读与菜单期间隐藏并保留剩余展示时间，回现场再显示；未读消息仍留在手机中。

最初怀疑的 F 查看物品与手电双触发没有在真实视口按键中复现，未改动原有 F 行为，新增回归保护该操作。
