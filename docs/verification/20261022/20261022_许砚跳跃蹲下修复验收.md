# 许砚跳跃、蹲下修复验收

## 修复结果

用户反馈「身体或腿扭曲、朝向不对」。已在Godot中复现旧动作的手臂与膝盖扭曲，改为沿用许砚原模型、Skin和材质，重新转换七段动作到原Godot骨架坐标轴。没有重新生成或替换角色。

- 七段动作：起跳、滞空、落地、蹲下、蹲姿待机、蹲行、起身。
- Blender来源是现有 `source_art/xuyan_motion_repaired.blend`；原GLB和源文件保持不变。使用网格空间形变重建原骨架动画，避免同名骨骼的局部轴差异。66骨骼，每段198条轨道，逐帧重建位置误差小于0.000005m。
- 起跳当帧进入动作，完整播放短起跳再转滞空；落地和蹲起根据片段实际时长衔接。跳下台阶不触发主动起跳姿势。
- 暂停冻结主角动画及过渡计时，恢复后继续。
- 根据实际8权重蒙皮，将人物视觉根节点抬高3.33cm，抵消静态包围盒与Idle鞋底的差异。四个蹲姿片段各5个时间点，鞋底在地面上下1.2/1.8cm范围内；没有移动物理胶囊来掩盖穿模。
