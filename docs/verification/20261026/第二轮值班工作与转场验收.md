# 第二轮值班工作与转场验收

开始2026-10-25，收尾2026-10-26。现有工程F:/诡异事务局/得利洗衣店_接手工程，起点5872922。本轮按用户“值班室发布工作，在工作中遇到困难”及“可以”的授权落地；没有恢复旧24小时任务。

## 玩家现在做什么

1. 每夜先到原1F传达室签收工作单。工作单包含工作地点、实际要求与完成条件；2F柜台可以随时重读、看未完成事项、提交续查，不要求每个小步骤回1F。
2. 第一夜先读须知，实际擦三号机玻璃。鼠标按住来回擦；也可按住空格移动抹布。清洁覆盖与读档相同，外侧污迹被擦除而内侧小手印保留；使用原洗衣机实时3D近景，世界实物也显示同一印痕。
3. 检查九号机的未取单，核对日期/机号/取衣状态；到七号机确认原衣仍锁着。抄录两遍广播并比较差异；为来客清点布袋现有五件与待取原衣，错误填写有复查方向；停电后查毛巾绣字。
4. 阶段工作完成后，在2F柜台选择继续值守。短过渡只推进到最早待处理事件，现场对白/人物入座/黑屏未结束则不推进；新物证仍需亲自查看。未知停电等不会提前显示在柜台按钮里。取消/暂停不会偷偷写入将来时间，保存使用已确认时间。
5. 第二夜工作单要求核实收件人：老周、照片背面、证件与医院挂号件接回原流程。第三夜工作单要求安全检修与原衣交还，保留隔离→泵→阀门→固定梯→现场复核，不改变三夜唯一结局。周小满仍去向未明。

不使用T时钟也能走完整案。时钟作为可选工具保留，现实1分钟=游戏10分钟；阅读/暂停期间停时，关键事件按未触发顺序补，不跳证据。旧第二夜、已交班及结案档兼容，不强制补第一夜新增杂务。

## 转场实现与实测边界

新增scene_transition：资源使用线程读取，运行时另换的PBR贴图也单独预读；接受通知书后提前准备街道资源，出街后预读洗衣楼。街道按空间块、洗衣楼按楼层分帧组装。节点/碰撞仍在主线程创建，两个场景继续复用。实际显示读取数量/组装阶段，失败可重试或返回；确认真实落地后才交还移动控制。原同步建场入口保留供存读档/巡查。

下表是同机脚本实测秒数，全部测到控制恢复；“首次”指该进程首次进入，不是清空所有驱动缓存的新电脑。正常游戏有通知书阅读和街道步行期间的预读；压力测量直接进场，不计这些提前准备机会。
