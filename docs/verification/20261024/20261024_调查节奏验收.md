# 第一案调查节奏调整与验收

在现有工程中处理自动路线暴露的空等、重复提醒和事件补播问题。保留三夜、唯一A结局、既有证据与人物、10倍时间流速；未增加案件或替换场景。

## 发现与修改

1. **交衣后仍然催衣。** 改前第三夜交还第六件后，跳到03:55会一次补发02:31擦拭、03:10“还差一件”和03:40“是不是洗好了”。现在调查段与尾声分开，认领后只推进交班、回执、录名、天亮与阿七。晚完成不会把时间倒退到03:54/03:55。
2. **后两夜重复第一夜时间表。** 第一夜保留00:01、00:20、01:10、02:30、02:31、03:10、03:40的完整铺垫；第二、三夜只保留01:10来客这个定时节点，其余推进来自既有的住户对话、物证检查、配电、排水及地下观察。不再每晚机械重播两遍广播、停电、擦拭和数五件。
3. **第二夜材料齐全仍需空等。** 身份材料、老周口述、钥匙与姓名回报完成后，直接指向柜台提交续查。确认提交后由原交班接口等待至04:00、结算800元并引导回家，不必逐个拨过重复事件；缺资料仍提示复查，工资不能重复领取。
4. **迟到或读档会集中追赶事件。** 时钟预览与实际触发共用`case_pacing.gd`，按仍适用、尚未触发的最早项推进。每次只处理一项；字幕、语音、人物入座、停电、阅读和演出结束后再处理下一项。临界点前0.01游戏分钟也不会跳过广播；没有事件时保留时钟并说明当前目标。
5. **提示叠加。** 去掉每次换物件自动发送的`goal_`短信，以及广播/询问时再抄送一次目标的短信。屏幕主目标、准星、入口标记和H帮助继续工作；卡住45秒展开路线，90秒只发一次手机提醒。阅读、单句字幕、选择和隐藏面板的活动对话也不计入卡关时间。重要入职、报到、续查、交班和泵操作消息保留；通知与提示音等现场对白空档再出现。
6. **人物行走期间反复尝试交谈。** 第二、三夜也明确区分“等她坐稳”和“走近交谈”，避免玩家追着行走人物反复按E。
7. **回家目标被时钟覆盖。** 交班后的室外时钟提示回公寓床边休息；第二、三夜使用续查话术，不覆盖成首次报到。已认领但缺少旧结局字段的存档可正规化为唯一A，并继续到阿七和结案，不重复授予认领物品。
