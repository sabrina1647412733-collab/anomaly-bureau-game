# 街坊生活化、情境反馈与门前样板精修

在现有工程完成上一轮约定的四项工作：修短步接地、增加两位街坊的生活行为、按剧情提供反馈、精修两处门前环境。保持许砚与既有剧情角色、十个地标、第一案三夜及唯一结局。

## 改动

- 用户两份模型各保留原网格、材质、皮肤和Walking/Running，新增ShortWalk、备用WalkGrounded、左右换步、理袖、拢外套和看街，连同Idle共10段动作。正式移动为2.4秒走0.72米并脚停止；根位移与骨骼共用动作曲线。90度转身由换步和匹配的根yaw曲线完成。
- 店主在原电料店门旁理袖、看店，女住户拢外套、看街；雨停时选择看街。两人错开节奏，在各自檐下短距离往返。先检查全路线地面与胶囊空间，再用CharacterBody3D扫掠移动；遇玩家停让，离开后续走，避免穿过人和物件。
- 中心准星仍只选一个目标，驻足时可问路。回复根据已接单、已办交接、各夜当前调查目标与交班休息变化，不反复催已完成报到。街坊不发放证据、不改主线，也不提前透露事故真相或把孩子写成已确认死亡。
- 落脚点调用既有空间脚步音效；暂停时停播，离街时清止。没有新增街坊对白配音，现有剧情语音系统不变。
- 门前补有厚度和端盖的折边滴水件、螺钉、低矮门槛收边、嵌入式墙脚修补与排水口下局部痕迹。保留原店面开口、椅盆/柜、花盆、17簇小草与4个道具碰撞；新增几何避开人物短线和玩家通道。hero层为54,526三角形/20批次/约2.48MB。
- 修复首次从室内读档、尚未创建街道时丢失人物现场的问题；暂停、读档、新游戏、离街和返回均处理动作状态。损坏可选字段、相位或路线记录安全拒绝。旧存档继续可读。

## 模型动作检查与限制

离线蒙皮采样以每人的真实骨长/骨轴求腿部IK，并迭代校正鞋底高度和支撑面中心。ShortWalk支撑脚速度p95约0.019—0.029米/秒，转身约0.025—0.038米/秒；比首轮明显降低，仍不是任意中断和混合下的绝对零滑步。暂停与停让后的短混合、近距离衣袖与手部表现仍应在允许可见试玩时继续检查。

Blender后台生成五相位检查。转身和行走的离线审查使用同时驱动网格/骨架的公共根，按正式根曲线移动；没有拿原地静止骨架图代替转身。联系图明确标注OFFLINE POSE QA，只能证明离线姿态，不能冒充Godot街道画面。两份原用户文件未修改，原二进制前缀与走跑动作保留。
