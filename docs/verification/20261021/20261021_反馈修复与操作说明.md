# 得利洗衣店 · 反馈修复版（2026-10-21）

解压导入包，用 Godot 4.7.2 导入同目录 `project.godot`，按 F5。建议选择“新游戏”，从房东催租来电开始体验新版动机与引导。旧版兼容存档可继续，缺失的工作说明和便携时钟会补齐。

## 这次修复

- 第二封通知书原先埋在活页本里。现在根据真实桌子的模型尺寸摆在桌前空位，贴合桌面，有实际封面文字。已检查门下与桌上两次信封都能被瞄准并用 E 拾取。
- 手臂持物使用独立深度画面，近墙时会收低，减少手机、手臂与墙面、桌面的穿插。手机、信件和时钟有独立持物外形。
- 上层补全外墙、三楼回廊围护、楼梯间和屋顶收口。修复折返平台被台阶占住、上层实心阶梯、屋顶整板封住楼梯等问题；三楼到四楼、五楼和屋顶均检查实际角色上下行走。
- 修正门板半截埋在地板下的问题，关闭的门增加实体碰撞。四楼护墙板按门洞切开；三楼衣柜移离卧室入口、修整侵入床头的隔墙；四楼杂物间移开门前床垫、纸箱并拓宽门洞。
- 房东来电改为催租并替换对应中文合成配音。接听后自动收到派遣科招聘消息，说明为什么去洗衣店、去哪里、何时报到、工作内容和报酬。
- 工作目标：今晚23:40，到临江里17号（老街27号院）二楼的得利洗衣店值夜班；观察异常、记录线索，04:00交班，报酬800元。通知书确认后从出租屋房门出发。一楼到二楼有明确任务提示。
- 手机新增可保存的任务消息、未读提示和通话页新消息卡片。报到、广播、来客、清点衣物、交班会有阶段提醒；长时间没有推进时，会给一次当前目标提示，避免重复刷屏。
- 背包改为6×4的固定正方形格子，含空格、物品图标和选中边框；物品较多时继续扩行。

## 时间与时钟

右上角显示24小时制“时:分:秒”。按你选择的倍率：**现实1分钟 = 游戏10分钟**。出租屋从23:10开始，去洗衣店途中推进到报到时间；进入店内后沿同一条事件时间线推进。

黄铜时钟在同意入职后出现于书桌。可以 E 拿起、B 收纳，再从背包取出。即使出门前忘了拿，转场时也会带上，避免到店后无法拨时。旧档案进入洗衣店时也补发时钟。

**T** 随时打开便携时钟。支持拨快10分钟、30分钟、到下一关键事件。拨时会在下一事件处停住；必须先处理03:40的回应，才能继续到交班，避免一次跳过整段剧情。暂停、手机、背包、记事本、信件和选择界面停走时间。

关键时点：23:40报到；00:01广播；00:20第二遍广播；01:30来客；02:30停电；03:10清点衣物；03:40回应；03:55交班；03:56领物；04:00天亮；04:01长椅；04:02归档。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 鼠标 | 行走 / 视角 |
| E | 瞄准场景物品进行交互；空闲处查看手持物 |
| F | 查看手持物；空手时切换手电 |
| B | 有持物时收纳；空手时打开背包；背包内关闭 |
| T | 打开随身时钟，查看下一事件与拨时 |
| Tab | 记事本 |
| ESC | 退出当前查看界面；自由活动时暂停 |
| 鼠标 | 手机应用、接听、消息卡片、背包选格、时钟按钮 |

已有本机设置会保留。如果听不到音乐或配音，主菜单“设置”中调高音乐、音效音量；此前本机这两项为0。

## 范围与已知限制

本版完成这轮反馈涉及的第一夜流程与场景修复。401、402、503等剧情锁门有实体门和交互反馈，仍保留当前夜晚的限制；没有扩写第二、第三夜。手机相册与地图仍是剧情用的简化界面，部分通用持物外形仍可精修。

自动检查和截图覆盖剧情、存读档、模型位置、实际输入、楼梯及房门通行；没有据此宣称所有地点绝无穿模，也未完成人工全程试玩或长时间性能、音箱听验。中文语音为离线合成配音。少量历史测试退出仍有 ObjectDB / Texture 释放警告。
