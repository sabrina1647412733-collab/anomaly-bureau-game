## 保留的结构

- 公寓02入口(169.88,99.96)→公寓巷向南→老街交汇约(167,127)→向西至得利01入口(145.88,120.8)。
- 老街原宽4.6米，公寓巷2.9米，沿用路网及原碰撞地面。十个地标名字、功能、入口不变。
- 洗衣楼外部继续五层15.8米；电料店保留1.6米门洞、1.65米浅进深及已有柜台，不能照概念图擅自扩出新商店空间。

## 设计落地分区

| 区域 | 具体内容 | 尺度及通行要求 |
|---|---|---|
| 右侧民房门边 | 编织藤椅、盆凳和掉瓷搪瓷盆，门框五金、木门接缝 | 放在门侧；先检查真实胶囊通行、旧花盆/扫帚和门前净空，机位可见性也必须复核 |
| 左中景电料店 | 原浅店面，墙挂电线圈、灯泡盒、旧分格窄抽屉柜 | 陈列符合电料用途；不重复柜台、不扩大门洞、不侵入道路 |
| 两侧住宅及附房 | 不同厚度的窗框/窗台、波纹雨棚、雨棚侧封、落水管与固定箍、局部空调 | 保持建筑质量和轮廓；空调避开窗户，雨棚支架接墙，附房不再悬空阳台 |
| 墙脚和转角 | 有边界的修补灰泥、局部露砖、旧弧瓦、少量裂缝草 | 由位置和使用痕迹组织细节，不把全墙刷成相同脏绿色，不铺满随机杂物 |
| 路面及边沟 | 合理尺度的沥青颗粒、粗糙度变化、局部雨湿、排水口 | 沿用同源道路地面；不叠整块共面地板，不把整街变成镜面水面 |
| 上部空间 | 依附原电杆与墙面的服务线、绝缘子、管线层次 | 不能低垂进人行高度或穿窗，不额外改动整张地图 |

## 制作顺序与文件分工

1. 以已跑通的结构作白模基础，锁机位、门洞和路线。
2. Blender原街道生成工具精修样板范围立面并输出原空间批次；近景道具单独输出三个小批次，保留可编辑源与旧Git版本。
3. Godot修正PBR的米制纹理比例、有向triplanar法线、粗糙度、AO和局部雨湿；近景道具共用已有木/金属材质，编织/搪瓷保留自己的材质。
4. 在真实引擎查看白天和夜雨、近景和反向机位，按看到的问题修整，最后做相关路线/天气/存档复测。

主要实现：`build_street_renewal.py`、`build_street_hero_props.py`、`street_surface.gdshader`、`street_world.gd`、`street_hero.gd`。目标是这段可游玩的场景，不以一次把全镇414座普通建筑精雕作为交付标准。

## 实机验收边界

参考图锁定环境层次与气质；图像生成中的细部不是工程尺寸来源，尺寸以原布局及生成manifest为准。验证分别记录材质探针、真实玩家相机、实际键盘路线和性能；固定机位60帧上限不代表其他电脑性能。最终结果写入同日实机验收记录，不提前宣称已达到照片级或商业游戏全套质量。
