## 本轮实际改动

- **店堂与楼体**：沿用批准的`laundry_finish`视觉模块及`laundry_rebuild`碰撞模块；追加Blender制作的壁架、洗涤用品、折叠毛巾、镂空衣篮、双管灯、风扇与管线。墙面改为真实灰泥/瓷砖纹理，地面加粗糙度及局部潮湿变化，贴图开启mipmap，消除兼容渲染下旧高频噪声造成的条纹。灯具有实体，柜台暖光与店堂冷光区分；B1池壁、井体和池底也接入相应表面。原GLB、原白模和之前的精修资源保留。
- **可走路线**：传达室签名面移到玻璃外；出租屋休息点移到可见床面；一楼地下检修口补实体盖板与匹配碰撞，避免接近交互时直接坠井。进入梯子过渡时暂时隐藏盖板，完成后恢复。导航从303/304、后房、502/503、配电房、存档间先退出正确门口，再引向其他房间/楼层；B1布鞋从侧面开口瞄准，避免隔墙操作。
- **第一人称**：独立CC0解剖拓扑起点、连续掌指网格和外套袖口，共七种GLB握姿；纸张、照片和毛衣双手，其余右手为主。第三人称许砚模型和66骨骼修正动作保留。持物切换采用放低/抬起过渡，快速切换以最后选择为准，收纳会取消旧过渡；暂停冻结未结束动作。照片显示实际家庭照片；文件正文按纸面宽度换行。
- **调查**：新增照片翻背面、洗衣单逐字段检查、医院挂号件编号选择、衣物补线/袖口/干湿核对和事故结论复核。错误封套会放回，错误结论给复查方向；只有正确核对才取得医院件和事故记录。照片背面检查被引导系统明确要求，检查标记保存在campaign flags。沿用既有背包数据和阅读状态，不新增第二套任务/存档系统。
- **演出**：信封出现、七号机异常、周秀兰数衣及退水后的竖井，共四段实机相机观察。空格跳过，Esc暂停；字幕、语音及相机同步结束。临时停机不会写成永久停机，退出/存档恢复为原play/prologue。演出期间隐藏任务HUD，结束归还原相机和位置。
- **声音**：沿用普通话合成对白、既有音乐与环境声。新增原创合成翻纸、短信、转阀和退水音效；空间声增加室内/B1回声层次，经WorldSFX发送到原SFX总线，四项音量设置保持。手机横幅缩到右上角，关闭通话和跳过演出都立即停语音；事务局消息仍以接受信封为前提。
- **控制**：新增L独立开关手电，默认关闭以保留场景照明；随存档保存开关。进入街道保留玩家已选择视角，V轮换仍可用；场景淡入完成前保持过渡状态，避免短暂报告可移动但实际控制尚锁定。

新增可编辑资产为`source_art/view_hands_v1.blend`和`laundry_detail_v1.blend`；来源与构建脚本见对应目录README/SOURCES。没有下载未注明许可的新素材，既有Kevin MacLeod配乐署名保留。

## 连续三夜正常路线

`normal_route_review.gd`本轮最终连续运行从新游戏开始，无中途读checkpoint续跑：

1. 房东电话→门下信封→接受派遣→取得时钟→出门，经街道步行到店。
2. 第一夜签交接簿、规则、洗衣单、七号机、广播、周秀兰、后房旧招牌→交班→街道→出租屋休息。
3. 第二夜402老周、303婚证/照片背面、304接种记录、503信箱、廊桥医院件、老周口述/管线、403钥匙、告知姓名→交班→街道→出租屋休息。
4. 第三夜502—503维修通道、七号机钥匙、解除门栓、屋顶重复衣物/维修印、隔离电路/启动泵、B1阀门/通知/水线/检修梯/布鞋、后房水痕、事故复核、七号机原衣、交还周秀兰。
5. 交班、工资回执、录名、天亮、阿七尾声→唯一结案。

最终日志：`finished=true, errors=[], interactions=69, state=case_end`。该驱动用正常角色物理移动、中心瞄准和按键/界面按钮；街道路由在测试端依据碰撞寻找路径，玩家实际走过，不传送到调查点、不直接授予证据。等待使用游戏自身的T时钟。此项是有窗口的自动驾驶验收，部分对白/镜头被正常跳过，不冒充人工逐分钟完整试玩。

本轮调试中确实先遇到过传达室、休息点、房间退出和检修口的问题；修复后上述最终运行从头连续通过。旧失败日志不算最终通过记录。
