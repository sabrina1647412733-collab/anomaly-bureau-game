# 安装器默认临时目录错误5修复

日期：2026-10-25。工程起点0432a01。用户实机截图显示，双击0.7.0 Setup时，在创建C:\Users\Sabrina\AppData\Local\Temp\is-*.tmp期间错误5（拒绝访问），尚未进入安装位置选择页。此问题不同于前次已复现的开始菜单/HKCU写入失败。读取目录ACL不足以确定拒绝来源，未修改用户权限或安全软件。

## 原验收的遗漏

前次验收把整个测试进程的TEMP/TMP指定到F盘，绕过了默认临时目录的失败条件，因此不能宣称原Setup的默认双击启动已通过。用户截图是此失败的直接证据。此次不以重新编译原Inno脚本充当修复。

## 改动

- installer/TempHost.cs：小型.NET Framework引导在Inno SetupLdr之前选择可写TEMP。优先F:\AnomalyBureau-SetupCache，其次程序旁缓存，最后系统可写TEMP；每次独立随机目录并限制为当前用户访问。只对子进程设置TEMP/TMP，系统和用户环境不变。
- 完整Inno负载附加在引导EXE尾部，提取时校验长度、魔数和SHA256；失败不运行负载。安装结束删除所提取的完整Setup，保留诊断日志。
- 卸载快捷方式指向同类临时目录引导；先复制并脱离安装目录后启动原生卸载程序，避免自身文件占用。卸载默认保留玩家数据。
- build_installer.ps1支持只重建安装器，build_windows.ps1统一调用；windows_installer.iss包含卸载引导。不改游戏基础文件、资源包、更新协议、剧情、UI或存档代码。
