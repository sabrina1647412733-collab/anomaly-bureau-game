# 接手优化版 · 2026-10-20

工程由原交付 ZIP 解压为独立工作副本；原交付 ZIP 保留。修改前主要源码备份位于工作目录的 `接手验收/修改前源码/`。

## 流程与操作

- 处置选择后继续交班，04:00 天亮、04:01 阿七、04:02 结局归档可以按正常总控顺序到达。
- 洗衣店不再运行旧车站到站时间轴，旧车站的 T 键快进也不作用于本案。
- 时间基准统一为 23:40 起算；首次广播 00:01、第二次 00:20、老太太进入 01:30、停电 02:30、数衣服 03:10、选择 03:40。
- 修正 C 键“顶替”，选择支持鼠标点击；缺少物品时禁用对应按钮。
- 复用演员行走驱动，角色进入后会实际走向座位，不再只在测试脚本中移动。
- 暂停停止玩家移动，恢复选择状态时不会误切到自由走动；结局 ESC 可返回菜单。Q 键疑点标记也作用于洗衣店。
- 新游戏清理旧洗衣店、背包、记事本、信封和时钟状态。

## 本案存档

新增版本化的案卷 00184 存档。保存当前位置、视角、时间、已触发事件、钥匙、后门、线索、背包、记事本、未读字幕、选择与结局状态。读档重建物件与演员的可见状态，避免重新发放物品。文件先写临时文件再替换，保留旧车站存档文件；旧车站档案在本案载入页标为保留，不能误当本案续玩。

本轮只支持当前已经制作的出租屋与第一夜；第二、第三夜仍未开发。过场、手机、通知书等临时界面需先关闭后保存。

## UI

- 主菜单调整字体、对比度和本案信息卡。
- 字幕使用独立深色底板，目标与钟点分区，增加持续操作提示。
- 三选一改为三个独立处置按钮，显示物品是否齐备，并支持键盘焦点。
- 结局改为纸质归档页，正文可滚动，提供返回按钮。
- 存档页切换为本案专用布局，修复暂停面板覆盖槽位列表的问题。
- 记事本增大正文字号与页签宽度；设置滑条接入即时应用。
- 使用 1600×900 设计画布等比缩放。

## 规则选择

本轮保留交付版 A/B/C 三种处置与物品条件：A 需要童装毛衣，C 需要自己的卫衣。三夜正式版的“名字门槛”和隐藏 D/E 尚未接入；不把尚不可玩的内容显示为已完成。

建模提升计划另见 `建模提升方案.md`。本轮仅完成基础材质、砖缝、照明与灯具细节调整，没有重制角色模型。
