# 手机、背包与声音更新 · 2026-10-20

用 Godot 4.7.2 导入同目录的 `project.godot`，按 F5。建议先选“新游戏”体验新的信封流程，已有兼容存档也能继续。

## 操作

| 操作 | 按键 / 方式 |
|---|---|
| 拾取、与场景交互 | 靠近物品按 E |
| 手机、信件查看 | 手持时离开其他交互点，按 E |
| 收纳手持物品 | B |
| 打开 / 关闭背包 | 空手按 B；背包中 B / ESC 关闭 |
| 从背包取出 | 点击物品，再点“取出并手持”；也可按 E |
| 手机应用 | 鼠标点击；底部圆点回桌面；ESC 退出查看 |
| 接电话 | 打开手机，点击“接听” |
| 信件 | 鼠标滚轮阅读；第一次 E 同意 / R 拒绝；第二次只能同意 |
| 地下室服务梯 | 一楼铁盖附近出现提示后按 E；地下室出口同样按 E 返回 |

## 本次完成

- 手机增加锁屏、桌面、聊天列表和对话、电话、钱包、相册、备忘录、离线地图、时钟、设置。相册为剧情占位卡片，地图为简化离线示意，不接真实社交或地图服务。
- 拾取手机后移除场景中的机身与屏幕；B 收纳后手中手机消失；背包可重新取出。背包为三列物品格、详情和取出按钮。
- 新增第一人称袖口、手掌、分节手指与持物动作；手机和通知书有独立模型，其他物品暂用通用持物外形。它们是程序化基础模型，仍可继续精修。
- 信封第一次出现在门下。拒绝后进入垃圾桶，灯灭后重新出现在桌上，需要再次拾取，第二次只有同意。同意后收入背包，随后可取出重读。
- 通知书改成浅纸深字、大字号滚动正文，保留原稿五条须知；同意后留在出租屋，接听电话后主动从房门出发。
- 洗衣店门口打开实际碰撞通道；一楼至三楼梯段分侧，补三楼回廊。服务梯增加攀爬过程，修正地下室顶棚和落脚空间。
- 新增原创合成配乐、出租屋雨声、洗衣机环境声、手机铃声、敲门、门、纸张、收纳、按键和铁梯声音。中文配音使用本机离线语音合成，共 7 段，含来电、两次广播与关键人物台词。
- 音乐、音效、配音和环境声统一走音量总线；暂停停止背景音与配音，配音播放时降低配乐；手机设置支持铃声静音。
- 存档保存手机所有权、已同意的通知书与手持状态，读档不会重新生成已取走的场景手机。
