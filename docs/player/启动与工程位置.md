# 打开当前游戏

本机持续更新的主工程：`F:\诡异事务局\得利洗衣店_接手工程`。

- 直接游玩：双击工程根目录`启动游戏.bat`。
- 编辑游戏：双击`打开Godot工程.bat`，进入编辑器后按F5。
- 在Godot项目管理器里导入：选择工程根目录`project.godot`。旧C盘“缺失项目”不是当前工程，旧F盘其他副本也不是本次持续更新位置。

本机`F:\ChatGPTProjects\诡异事务局\`中的“游玩当前版本”“打开当前Godot工程”，以及原“试玩优化版”“打开优化版Godot”快捷方式均已指向主工程。`F:\诡异事务局\启动-得利洗衣店.bat`也已重定向到主工程；这些个人快捷方式无需放入Git。

需要Godot 4.7.2。启动脚本会从PATH寻找对应程序；其他电脑若没有该PATH，可直接通过Godot导入工程，或设置`GODOT_EXE`为该电脑的引擎程序路径。首次导入资源可能稍慢。

开发缓存与启动日志在工程`_预览`，玩家存档在工程`_玩家数据`。本次修复没有移动或覆盖玩家存档。Windows批处理文件必须使用CRLF，Git已配置保留此格式。
