# 开发者巡查

直接打开现有游戏，在主菜单点击“开发者巡查”，或在正常游玩时按F6。也可双击工程根目录“开发者巡查.bat”直接打开登录框。

账号为`sabrina`，密码使用用户在聊天中指定的口令。每次进入巡查都要登录；密码输入隐藏，不保存明文，也不提供命令行免验证入口。此验证是本地游戏的防误入门槛，不是联网账号或服务器权限系统。

## 地点与移动

登录后可搜索24个检查点：出租屋、回潮镇10个既有地标、第一案门厅/洗衣店/七号机/柜台/3F/4F/5F/屋顶/B1，以及第二案1F/8F/16F/17F。角色显示工程当前已接入资源，不会自动替换用户刚提供的新Meshy模型。

| 操作 | 按键/入口 |
| --- | --- |
| 登录、打开或收起面板 | F6 |
| 切换自由飞行和正常行走 | F7 |
| 回当前地点安全站位 | F8 |
| 截图 | F9，或面板截图按钮 |
| 隐藏/显示巡查标识 | F10 |
| 打开/收起面板 | Esc |
| 飞行移动 | WASD和鼠标；E上升，Q下降，Shift加速 |
| 正常行走 | 沿用WASD、鼠标、跳跃和蹲下；只有面板收起后才能移动 |

跳转时先检查地面和角色胶囊是否有站位；飞行转行走时若当前位置不能站立，回到当前地点的安全站位。巡查里不触发正常E剧情交互，查看锁门后的空间可用飞行或地点跳转。

面板支持上个地点、安全站位、检查补光、保存/恢复视角和固定室外时间/雨量/路面湿度。时间和天气滑杆不会推进案件证据或派遣。室内保持该场景自身灯光。

“重载当前区域”重新组装街道和案件场景，并重新载入已导入的GLB缓存；修改GLB后先由Godot完成资源导入。出租屋是程序构造，布局代码改动需重启游戏查看；重载按钮仅重置其当前展示。

## 进度保护与数据

- 正常游玩进入巡查前捕获临时现场，退出巡查后恢复进入前的案件、背包、位置和时钟；从暂停界面进入时返回暂停界面。
- 阅读、手机、背包或对白界面需要先收起，再按F6进入。完整过场中不进入巡查。
- 巡查期间不允许写正式剧情槽位，档案和路径切到独立数据范围，案件时间线停止。第二案17F只临时显示，不要求先打完剧情。
- 退出游戏时若从正常游戏进入巡查，只保存进入巡查前的正常现场，不保存巡查场景为剧情进度。
- 视角、地点及截图放在工程/游戏旁的`_开发者数据`文件夹。当前作者工程位于F盘，输出仍在F盘。视角存档不包含密码，正常玩家数据仍使用原来的`_玩家数据`。
- 本轮只实现巡查第一阶段，巡查默认静音；人物动作切换、碰撞线框、声音面板和剧情节点预览尚未加入。

实现此功能没有恢复之前暂停的美术/剧情任务，没有替换新角色，也没有重新制作安装包。
