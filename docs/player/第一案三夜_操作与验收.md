# 第一案三夜 · 操作与验收

更新日期：2026-10-26。开发时仍导入本工程的project.godot，按F5运行。本轮改在原F盘源码工程；已安装与GitHub公开v0.8.0不自动包含第二轮改动，等待账号恢复再同步。不重开替代项目、不覆盖玩家存档。建议用新游戏体验完整工作任务；旧现场继续兼容。

## 操作

| 按键 | 用途 |
|---|---|
| WASD / 鼠标 | 移动 / 看向 |
| 空格 / Ctrl或C | 跳跃 / 蹲下（已有对应角色动作） |
| E | 中心准星对准并走近物品后交互；对白中推进对话 |
| H / F8 | 展开当前任务提示 / 脱困回场景安全入口 |
| F | 查看持物，调查文件打开可滚动全文 |
| L | 单独开关手电，不必收起手中物品 |
| B | 有持物时收纳；空手时打开方格背包，可取出物品 |
| T | 打开已获得的时钟，跳到下一事件或提前若干分钟 |
| Tab / V / M | 记事本 / 三种视角轮换 / 街道大地图 |
| Esc | 关闭界面或暂停，暂停菜单可保存现场 |

实物检查可点击按钮或按对应数字；照片需翻背面再记录题字，医院封套核对27—503—1107，衣物检查袖口/补线及干湿，事故复核需逐项选择有证据的结论。错误编号或结论可以复查，不丢证据。四段观察演出使用实机场景，空格跳过；Esc暂停，跳过立即停音并归还原相机和位置。

右上角是24小时制，现实1分钟＝游戏10分钟。阅读调查页面时暂停时间，跳时最多到下一事件。调查不足不会进入坏结局，任务栏和手机提示下一步。

金色空心菱形指向当前目标或实际入口，中心小点用于选择一个物品；未对准或隔墙时不会触发。停滞45秒后展开路线，90秒后追加一次手机提醒。阶段工作完成时到2F柜台选择继续值守，不用时钟也能完成；T仍可选。来客行走时等她坐稳再交谈。

正常返回主菜单、暂停菜单「保存并退出游戏」或窗口X退出会写「_玩家数据/autosave.json」，主菜单「继续自动保存」恢复；手动三个槽位保留。桌面数据跟随工程或exe放在F盘，旧AppData文件只在缺少新文件时复制；浏览器版继续用user://。异常坠落自动回安全位置，连续异常回入口，也可F8手动修正。强制结束进程和断电不保证退出保存。

## 出租屋与第一夜

房东来电说明总欠租2160元。挂断后敲门，门下出现信封；可先拒绝丢掉，第二次出现在桌上且只可接受。接受后收入背包，事务局才发来恭喜入职、23:40到店值班和每夜800元的任务及注意事项。拿上手机和时钟，经房门进入回潮镇，沿地图去洗衣店，再进入独立室内。

1. 1F传达室签收当班工作单，上2F读须知；擦三号机外侧玻璃，确认留下的内侧手印。按住鼠标左键来回擦，或按住空格移动抹布，Esc收起可保留进度。
2. 核对九号机未取单的日期、机号与取衣状态，再查七号机。抄录/比较两遍广播；与来客交谈后登记现有五件与未取原衣；停电后看毛巾绣字。阶段完成可在2F柜台继续值守，每次只到下一现场变化。01:10来客，03:40回应；T不是必需。
3. 获得后房外门钥匙，调查后房与旧招牌。外门钥匙不能开七号机。
4. 在2F柜台交班终端申请续查，领取首夜800元；此时不录名、不结案。
5. 从1F出门回街道，到出租公寓床边休息。保留证据切换夜次，再经街道回店。

## 第二夜：核实姓名

1. 先在1F传达室签收第二夜核实身份工作，再到4F402按“两短一长”敲门，向老周出示洗衣单，获得303抽屉钥匙及503信箱钥匙。
2. 303抽屉查看结婚证、家庭照片；304书桌核对接种证，可另查作业、窗台石头及童鞋。
3. 1F打开503信箱，获得转存号27—503—1107。信箱钥匙不能开503房门。
4. 2F东侧廊桥通向楼内邮政存档间，按转存号取医院挂号件；不必去街道小邮局。
5. 回402核对老周口述、全楼管线图，再到403维修挂板取检修盒钥匙。
6. 回2F告诉周秀兰“周小满”，材料/姓名齐后直接在柜台申请续查（统一交班到04:00），领取第二夜800元，回出租屋休息。

允许提前找到原衣，但证据不足或未到第三夜不能提前结束。

## 第三夜：还原事故与认领

1. 签收第三夜安全检修工作，经5F502共用维修通道进入503，从内部打开房门，用403钥匙开检修盒，取七号机专用钥匙。
2. 屋顶核对七件重复童装、水箱旁维修印。复制衣服不能代替原衣。
3. 2F配电盘先隔离浸水回路，再接独立排水泵；操作反了保护跳闸，可复位重试。
4. 从1F检修梯下B1开排水阀；在安全步道查看停水通知、旧水位线，再放下竖井检修梯取蓝布鞋。
5. 回2F后房核对水痕，到B1整理事故证据。确认周秀兰遭遇倒灌；周小满的去向仍未明。
6. 七号机取出原衣，把第六件交还周秀兰。原衣从背包移出，留下交还记录。
7. 在柜台继续值守推进交班、工资、录名、天亮及长椅尾声；也可选用时钟。阿七正面出现，福利院旧址地址入包，进入唯一结案。

三夜共2400元，欠租2160元结清，余240元新收入；钱包另保留起始余额。第二案已有接入，最终品质验收另行安排；第三案尚未制作玩法。

## 手部、道具和声音

第一人称改用近景专用平滑网格，包含袖筒、袖口、手掌、四指与拇指，分别适配手机、信件、时钟、毛衣和童鞋。第三人称仍使用许砚已有角色；收纳后手与物品共同隐藏。

用户提供的毛衣、布鞋、衣袋接入现场与持物，优化后分别20708、13620、28442三角面。资源均在工程内，运行不依赖F盘，原始资产未覆盖。

已有音乐、环境声、手机、敲门等声音继续使用；新增事故记忆、老周口述、周秀兰确认姓名与道谢的中文合成语音，后续可替换真人录音。
