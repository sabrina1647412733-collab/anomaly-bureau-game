# 岚桥站 0017 · Godot 3D 版

《最后一班地铁：0017》的**表现层**（三层原型架构里最外层）。这不是界面原型，是可运行的 3D 实机版本；
交互层是 `deploy/v6-人话版.html`（单文件 2D 原型），交付层是界面设计稿。

## 怎么跑

- 引擎：**Godot 4.7.2 stable**（`Godot_v4.7.2-stable_win64.exe`）
- 工程入口：本目录的 `project.godot`（编辑器里「导入」后打开）
- 懒人方式：双击工作区根目录的 `启动岚桥站0017-游戏.bat`
- 主场景 `res://scenes/main.tscn`，窗口 1600×900，桌面用 Forward+ 渲染器

## 操作

`W/A/S/D` 移动 · 鼠标转向 · `E` 交互/推进对话 · `Tab` 背包 · `1`–`5` 切物品栏 · `Esc` 菜单 · `空格` 跳

## 玩法要点（与需求文档口径一致）

- 时间窗 **23:50 → 00:17**，`SEC_PER_MIN = 6`（现实 1 秒 ≈ 游戏 10 秒）
- **序章 + 四轮循环**，重置时只保留标记为「跨轮保留」的线索
- **5 件线索**：红灯延迟记录 / 倒放广播 / 停用钥匙 / 巡检簿 / 五号继电器
- 每个动作都有时间代价：合闸 −45s、推手柄 −60s、扳道岔 −35s
- 关键判定：手柄推到底时若已晚于 `T_LOCK`（00:16:43）或线索不足 → **结局 B**；
  正常锁进路则进二选一（`[E]` 公开真相 / `[R]` 封存）
- 三个 NPC 按轮次登场：林岚（序章）、周砚（第 1 轮）、陈默（第 2 轮）
- 三个存档槽：`user://save_1.json` ~ `save_3.json`

## 逐件精修与自查（开发用）

站体是一件一件做的，每件都走同一套循环：**生成 → 载入自检 → 0 错误 → 截图对比 → 提交**。

```powershell
$G = "C:\Users\Sabrina\AppData\Local\Microsoft\WinGet\Packages\GodotEngine.GodotEngine_Microsoft.Winget.Source_8wekyb3d8bbwe\Godot_v4.7.2-stable_win64_console.exe"
# 1) 载入自检：必须 exit 0 且没有 SCRIPT ERROR（末尾那条 ObjectDB 泄漏警告无害）
& $G --headless --path . --quit-after 90

# 2) 六个固定机位对比图 → _预览/look/<tag>_NN_名字.png
& $G --path . --script res://scripts/tests/look_shots.gd -- <tag>

# 3) 单个构件的定点近景 → _预览/look/<名>.png
& $G --path . --script res://scripts/tests/closeup.gd -- <名> <x> <y> <z> <yaw> <pitch> [fov]
```

**注意**：截图**不能**加 `--headless` —— 无头模式下 `root.get_texture()` 拿不到帧，脚本会一直挂着。

没有显示器时用工作区 `_tools/` 里的三个小工具把画面「读」出来（Pillow）：

| 工具 | 用途 |
|---|---|
| `python _tools/asc.py <png> [宽] [高] [crop] [gamma]` | 把截图降采样成字符画（默认 gamma 0.62 提亮，暗场景也看得清结构） |
| `python _tools/probe.py <png> <cx> <cy> <cz> <yaw> <pitch> <fov> "标签:x,y,z" …` | 把世界点投影到像素并报出该处的 RGB / 亮度，用来核对「这个构件在画面里到底有没有读出来」 |
| `python _tools/aim.py <cx> <cy> <cz> <tx> <ty> <tz> [目标高度]` | 由机位和目标点反算 yaw / pitch / 该用多大 fov |

### 1 · 五号继电器柜（7.40 m · 信号室 z 24.55–31.95）

**原状**：柜体、柜门、玻璃窗、五排继电器、端子排、铭牌、电缆槽的几何都在，但**一条都读不出来**——
信号室只有一盏顶灯，柜门面亮度只有 15/255；玻璃用的是不透明着色器，把柜内**整片挡死**（端子排与继电器排根本看不见，
之前量到的「端子排 29」其实是柜门自己的颜色）；铰链、把手、指示灯亮度 9–32。

**改动**：

- 新增 `shaders/glass_panel.gdshader`（在 `surface.gdshader` 上加 `ALPHA` + 掠射角 Fresnel），
  `station.gd` 的 `_mat()` 按材质里有没有 `alpha` 键选着色器，`glass` 材质设为 `alpha 0.34`。
  三处玻璃（继电器柜观察窗、售货机橱窗、广播台观察窗）一并变成真半透明。
- `level.gd` 的 `relay_cabinet()` 重做：踢脚 → 圆角柜体（倒角 0.045，整柜一个碰撞盒）→ 门框四压条 →
  玻璃观察窗（上腔五排继电器 / 下腔 14 组端子排，中间一条分界横档）→ 北端三副圆柱铰链 + 南端把手与锁 →
  铭牌（带四颗螺钉）+ 两盏柜顶指示灯（琥珀 / 红，各带灯罩底座）→ 底部电缆槽（槽体 + 两根电缆 + 六副支架）→ 柜内三盏小灯。
  第 5 排继电器用红色指示灯，对得上「五号继电器反馈慢半拍」的剧情。
- 信号室加第二盏顶灯：一盏灯照不到 7.4 m 的南半段。

### 9 · 坐下视角穿模修正

**报障**：坐下时视角穿模。

**根因**（两条，都实测过）：

1. `player.gd` 的 `_update_body()` 在「坐着」分支里**无条件把玩家身体显示出来**（`body.visible = true`），
   而第一人称坐姿眼高只有 1.22 m，正好落在自己**头部方块内部**（当时 y 1.045–1.275）——
   相机卡在自己脑袋里，所以坐着看哪儿都像穿模。
2. 坐姿本身偏低：髋关节 0.46 让臀块（y 0.34–0.54）直接插进座面（长椅座面顶 0.49、椅子 0.465），
   大腿（y 0.3725–0.5475）同样插进去；而小腿 0.42 + 脚 0.08 从膝高 0.46 够不到地面，**脚是悬空的**。

**改法**：

- 坐姿重算：髋 0.46 → **0.59**（大腿底面正好落在座面上）、躯干 0.54 → 0.67、头 1.04 → 1.17、
  肩 1.00 → 1.13；大腿下倾 11.8°（髋关节 `rotation.x = 1.3649`）、小腿保持竖直（膝关节 `-1.3649`）、
  膝盖落到 0.50，让**脚掌踩平地面**。
- 髋部网格偏移 −0.02 → +0.0125，让臀部底面与大腿底面齐平（站姿也一起受益）。
- 第一人称坐姿**藏掉自己的头**（第三人称照常显示）：`parts["head"].visible = (cam_mode == 1)`，站起来恢复。
- 坐姿眼高 `EYE_SIT` 1.22 → 1.32。

**验证**（临时脚本直接报各构件的世界包围盒 Y 范围）：

| 构件 | 改后 y 范围 | 判定 |
|---|---|---|
| 臀部 | 0.502 – 0.702 | 座面顶 0.490，高 1.2 cm，不再下陷 |
| 大腿（髋端） | 底面 ≈ 0.504 | 在座面之上 |
| 小腿 | 0.080 – 0.500 | — |
| **脚掌** | **0.000 – 0.080** | 底面正好落在地面 |
| 头（第一人称） | 已隐藏 | 相机不再卡在头里 |

坐下视角亮度：长椅 66.0 → 91.2、值班室椅子 78.1 → 104.9（平均绝对差 36–42，等于把挡在镜头前的那颗头拿掉）。
对比图：`_预览/look/_对比_坐下视角.png`。

**残留（已知未修）**：长椅座面深 0.84 m，而大腿长 0.433 m、又要从髋 0.59 下倾到膝 0.50，
所以在座面前沿约 10–27 cm 那一段，大腿底面会压进座面板条最多约 4 cm —— 被大腿自身挡住，正常视角看不见。
要彻底消掉只能把大腿改水平（脚会离地 8 cm，更难看）或把长椅座面改浅。
