# 诡异事务局 v0.8.0

## 新增内容
- 优化局内任务、交互文字、对白字幕，以及背包、手机、暂停和存读档界面。
- 支持按变化内容更新、跨版本资源复用和缺失文件修复。

## 修复问题
- 安装和卸载时自动选择可写的临时目录。
- 修复第二夜相关保存分流错误、保存后无法移动及读档残留临时状态。
- 补充存档备份、写入校验和明确的失败反馈。
- 下载失败可重试，并保留已校验的文件。

## 必要的已知问题
- v0.7.0及更早版本，本次请用完整安装包覆盖原目录升级，存档和设置会保留。
- 第二案的美术、表演与声音仍在完善。
- 洗衣店楼梯、后房、书架局部穿模及部分等待和引导问题仍待后续优化。

## 下载与安装
- 新玩家下载 **AnomalyBureau-Setup-0.8.0.exe**，运行后选择安装位置，建议F盘；默认创建桌面快捷方式，无需安装Godot。
- 已有v0.7.0及更早版本：先退出游戏，备份“_玩家数据”，再用本安装器选择原游戏目录覆盖升级。完整保留游戏目录中的文件。
- 资源清单、补丁BIN和SHA256SUMS供更新系统使用，新玩家无需逐个下载。旧版本的资源附件仍被新版引用，请勿删除。
