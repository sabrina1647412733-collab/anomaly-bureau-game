# v0.6.1 · 自动更新与开发者巡查

本版供已有Windows v0.6.0直接在游戏内检测和安装更新。首次游玩请下载`AnomalyBureau-Windows-0.6.1.zip`，完整解压到可写文件夹，双击`AnomalyBureau.exe`；无需安装Godot。保留整个文件夹，启动器、游戏EXE和PCK不可拆开。

- 新增账号验证的开发者巡查：主菜单或F6进入，直接查看出租屋、十个街道地标、洗衣店各层和第二案关键楼层，共24个机位。
- 支持飞行/行走、安全站位、时间与天气检查、视角记录及截图；巡查数据独立，退出恢复原案件现场。
- 集成启动时检查新版本、更新日志、下载进度和重试；独立更新器校验、备份、替换并重启，失败回滚，保留存档与设置。
- 同步当前街道及第二案运行资源。第一案保持三夜唯一结局；第二案仍是开发状态，最终美术、角色表演和声音尚未完成全案验收，第三案未开放。

## 下载选择

- **首次下载或旧0.3.x/0.5.x**：`AnomalyBureau-Windows-0.6.1.zip`。这些旧版本没有自动更新器，请完整解压新版，关闭旧游戏后备份并复制整个`_玩家数据`目录。
- **已经使用0.6.0**：重新启动游戏，或在主菜单“更新日志”中检查更新，选择立即更新。`AnomalyBureau-update-win64.zip`供更新器使用。
- `SHA256SUMS.txt`用于检查附件完整性。源码压缩包用于开发，不能直接当Windows游戏启动。

本次不提供Setup安装程序：此前初始化问题尚未完成验收。Windows测试版未购买签名证书；遇到防护提示请检查来源和校验值，不要关闭系统防护。

## 检查范围

开发者巡查已有70项功能检查和900p/720p实机界面检查。本次发行另检查导出包启动、版本识别和完整更新事务；这些不等同重新人工通关两案。遇到问题请记录版本、当前任务、地点和操作。
