# 第一案 · 美术与声音精修 v0.3.2

下载 `AnomalyBureau-Setup-0.3.2.exe` 安装，或完整解压 `AnomalyBureau-Windows-0.3.2.zip` 后运行 `AnomalyBureau.exe`，都不需要安装Godot。

- 洗衣楼八个区域的材质、倒角、照明与家具细节统一；洗衣机、滚筒、长椅、门和检修桌使用新增精修模型，保留审核过的通行结构。
- 修正周秀兰、老周、阿七的手臂方向与坐姿；修正阿七尾声座位、离场衣袋位置，以及303抽屉和照片的实体对应。
- 手部补光与肤色调整，拾取提示移开手机所在区域；沿用手机、格子背包和三种视角。
- 新增分区与事件配乐、室内外雨声、洗衣机空间声音、不同地面脚步、落地和机门音效；对白时配乐降低，设置支持四类声音独立调整。
- 保留三夜剧情、唯一结局、中心准星、任务引导、掉落脱困和退出自动存档。街道建筑名称、位置与功能不变。

源码9组相关回归341项通过。发行包另做三夜流程、声音和资源读取检查，以及Windows安装、启动与卸载验证；详细结果见源码验收文档。

配乐含 Kevin MacLeod 的 “Lightless Dawn”（CC BY 4.0），实录音效来自Freesound CC0素材；游戏内和安装目录均附署名与许可。角色对白仍为合成配音，尚无完整面部口型。

安装建议保留默认目录。本机默认目录的安装和卸载已通过；F盘工具目录下原位卸载未通过，其他自定义目录未逐一验证。需要放在任意文件夹时可优先使用免安装ZIP。
