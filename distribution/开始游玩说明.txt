诡异事务局 · 第一案「得利洗衣店」
Windows 游玩版 v0.3.2 / 2026-10-22

一、怎么打开
安装版：运行 AnomalyBureau-Setup-0.3.2.exe，按向导安装到当前用户目录。
安装后从桌面或开始菜单打开「诡异事务局 · 得利洗衣店」。不需要安装 Godot。

免安装版：把 ZIP 完整解压到一个普通文件夹，再双击 AnomalyBureau.exe。
不要在压缩包里直接运行。AnomalyBureau.exe 与 AnomalyBureau.pck 必须放在一起。
不要只发 exe 给别人，请发完整 ZIP 或安装包。

二、电脑要求与启动问题
本版面向 Windows 10/11 的 64 位电脑，尚未提供 Mac、Linux 或手机版。
优先打开 AnomalyBureau.exe。显卡不支持 Vulkan、启动报渲染错误或黑屏时，
可尝试同目录的「兼容模式启动.bat」（OpenGL 3.3），或开始菜单的兼容模式快捷方式。
兼容模式可能降低部分光影效果，较旧显卡仍可能无法运行。
首次载入资源与编译着色器可能需要等待，请勿反复打开多个窗口。
这是未购买代码签名证书的独立游戏测试版；请从本项目 GitHub Release 下载并核对校验值。
如果系统或杀毒软件拦截，请先确认来源、检查文件，不要关闭防护软件。

三、开始玩
主菜单点「开始值班」，从许砚的出租屋开始。
先接房东电话，挂断后查看门下的信封，接受派遣后再出门。
经回潮镇街道走到得利洗衣店门口，进入独立室内。
第一案共三个夜班，每夜交班后按提示回出租屋休息。
本版本只包含第一案，第二、第三案还没有制作玩法。

四、操作
W / A / S / D：移动。鼠标：看向物品。
屏幕中央小点是交互准星；对准并走近可交互物品，小点变金色，按 E 交互。
旁边有东西但没有对准时，不会自动和它交互。隔墙不能交互。
空格：跳跃 / 推进正在播放的字幕。Shift：快走。Ctrl 或 C：蹲下。
F：查看手中物品。B：有持物时收纳，空手时打开背包；在格子中选取物品可重新拿出。
T：取得诡异时钟后打开拨时，最多推进到下一事件。
H：洗衣店内展开当前任务提示。左上角显示当前目标与下一步。
金色空心菱形指向当前任务或途经入口，它与中心交互小点各司其职。
V：切换第一、第三、第二人称视角。M：街道大地图。
Tab：记事本。Esc：关闭界面 / 暂停。
F8：脱困修正；暂停菜单也有同名按钮。

五、卡住、掉进虚空怎么办
系统会把异常坠落的角色送回最近安全位置；短时间再次坠落时回场景入口。
遇到穿进家具、无法移动等情况，按 F8 或 Esc →「脱困修正」。
手动修正会回当前场景入口，任务、背包和游戏时间保持不变。
若正在阅读或进行对话，先收起页面 / 完成当前对话，再手动修正。
遇到异常请记录当时任务、楼层、位置及操作，便于后续修复。

六、保存与继续
暂停菜单可以保存三个手动槽位。
返回主菜单、「保存并退出游戏」或点窗口 X 正常退出，会写入独立的自动存档。
下次启动点主菜单「继续自动保存」。自动档不会覆盖三个手动槽位。
阅读中退出会回到现场，未结束的对白可能需要重新与角色交谈。
过渡或攀爬中退出会尽量恢复到最近的有效现场位置。
强制结束进程、断电或系统崩溃无法保证触发退出保存，重要进度请另存手动槽位。

存档位置：在资源管理器地址栏粘贴下面一行后回车：
%APPDATA%\Godot\app_userdata\诡异事务局\
autosave.json 为自动档；save_1.json 至 save_3.json 为手动档。
换电脑时可在游戏关闭后复制整个存档文件夹。
卸载仅删除程序，不主动删除该存档目录；新版本继续使用同一目录。

八、声音设置与鸣谢
设置里可分别调整音乐、音效、对白、环境四个音量。人物说话时配乐自动降低。
主菜单「声音与素材鸣谢」可查看作者与许可，安装目录附 credits.txt 和许可证。
本版精修了洗衣机、长椅、门、各层表面和家具细节，修正角色手臂与坐姿。
