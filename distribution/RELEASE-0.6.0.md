# Windows 自动更新与更新日志

- 首次安装本版后，游戏每次启动自动检查 GitHub 正式版本。
- 主菜单新增更新日志，可查看历史版本、发布日期和更新内容。
- 新版本支持立即更新、稍后更新、下载进度、取消及重试。
- 独立更新器校验、备份并替换程序；失败自动回滚，保留原有存档和设置。
- 更新中断后，通过 AnomalyBureau.exe 启动可恢复未完成的安装。

首次游玩下载 Setup.exe，或完整解压 Windows ZIP。后续游戏内自动使用 AnomalyBureau-update-win64.zip。请保留整个游戏文件夹，通过 AnomalyBureau.exe 启动。

本版以当前工作工程构建，保留已有剧情与美术进度；本次专项验收针对发行与更新机制，不代表尚在开发的第二案已经完成全案验收。
