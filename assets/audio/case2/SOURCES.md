# 第二案普通话对白

本目录 WAV 由作者本机已安装的 Windows System.Speech 中文合成声线离线生成，台词来自本项目唯一结局剧本对应的 `case2_dialogue_data.gd`；不是外部演员录音，也不模拟特定真人。

生成入口为 `scripts/tools/generate_case2_voice.ps1`，清单为 `dialogue_manifest.json`。许砚沿用 Kangkang，阿七沿用 Yaoyao；何伯使用较慢、较低的 Kangkang，孙素琴使用较慢的 Huihui。停顿在句内分段设置，字幕仍以同一行台词及实际播放结束为准。

这些音频是本轮可玩的合成对白版本，不能据此宣称完成专业演员表演。第三案只保留派遣引子。
