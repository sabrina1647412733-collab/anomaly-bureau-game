# 第一案道具

来源：项目作者提供的Meshy生成GLB，原件位于作者本机 `F:\角色3d模型\第一案道具`。本目录保存游戏优化版本，原始模型未覆盖。

| 资源 | 原始三角面 | 优化后三角面 |
|---|---:|---:|
| sweater.glb 藏青色儿童毛衣 | 331358 | 20708 |
| shoe.glb 蓝色儿童布鞋 | 435900 | 13620 |
| bag.glb 周秀兰的旧帆布衣袋 | 910198 | 28442 |

使用Godot ImporterMesh生成LOD后提取低面层级，保留UV、法线与材质，贴图边长限制到2048。`optimization_report.json` 为导出结果。`scripts/case1_prop.gd` 负责尺寸和朝向统一；运行仅依赖本目录资源。
