## 三、场景侧已经提供的接口（剧情线可直接调用）

```gdscript
# laundry_main.gd 里：
buildings["f4"]           # 4F 实例
buildings["f5"]           # 5F 实例
buildings["roof"]         # 屋顶实例
buildings["b1"]           # B1 实例  ← 蓄水池在这里
buildings["stairs_up"]    # 上层楼梯井
buildings["alley"]        # 后巷 + 消防梯
buildings["mail_office"]  # 廊桥 + 老邮局
buildings["power_room"]   # 配电房
```

**B1 蓄水池涨水**（剧本：每 30 秒 1 cm）：
```gdscript
var b1 = get_parent().buildings["b1"]
b1.start_rising()          # 开始自动上涨（每 30 秒 1 cm，涨到池口停住）
b1.rise_water(30.0)        # 也可以手动推 30 秒的量
b1.stop_rising()           # 停止
b1.water_base_y            # 当前水位（初始 -4.20，池口 -3.00）
b1.boiler_fire             # 锅炉火光（关掉就是熄了）
b1.fire_out()              # 熄火
```

**配电房总闸**（第三夜送电）：
```gdscript
var pr = get_parent().buildings["power_room"]
pr.set_breaker(true)       # 拨上总闸（只记状态，动画由剧情层做）
pr.breaker_on              # 当前状态
```

**4F/5F 的灯**（想让某层关灯时）：
```gdscript
var f4 = get_parent().buildings["f4"]
f4.lights["corridor"]      # 走廊灯 OmniLight3D
f4.lights["radio"]         # 收音机红灯（4F 那盏「错的光」）
```
