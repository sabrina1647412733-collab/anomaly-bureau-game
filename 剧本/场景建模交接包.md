# 4 · 三个致命的尺寸 / 坐标约定（都踩过多轮）

## 4.1 全尺寸 vs 半边长

| 位置 | `size` 的含义 |
|---|---|
| `laundry_art.gd` 的 `a.box()` / `a.bev()` / `a.col()` | **全尺寸**（`BoxMesh.size` 语义） |
| Blender 脚本里的 `box()` | **半边长**（`create_cube(size=2.0)` 再乘） |

混用会直接导致「整台机器只有一半大 / 家具横穿房间」。这个坑在玩具洗衣机上踩了两次、梳妆台上又踩了一次。

## 4.2 朝向

- Godot 里：模型「正面朝 −Z」，用 `rotation.y` 转到目标方向
- Blender 导出 glTF（`export_yup=True`）后：Godot 里也是「正面朝 −Z」
- **别靠猜**：先 `print(bound_box)` 看包围盒，再定 yaw。配电房在这上面栽了四次。

> **⚠️ 2026-10-20 更正（流程集成会话）**：
> 上面两条只对**建筑盒子 / 自建 props** 成立。
> **`assets/models/chars/*_Anim.glb` 四个角色模型的正面是 +Z**（四方位截图实测：
> 从 −Z 看到后脑勺，从 +Z 看到脸）。`char_actor.gd` 用 `atan2(d.x, d.z)`。
> 而且**包围盒量不出朝向**——必须四个方向各拍一张才知道脸朝哪。
> 详见 `_night/场景建模交接包_复核.md`。

# 7 · Blender 工作流

```bash
B="F:/诡异事务局/_tools/blender-4.5.14-windows-x64/blender.exe"

# 1) 建（产物先出到 _blout/，Blender 写不进 assets/）

# 2) 预览渲染（确认形体对了再接入）

# 3) 接入工程
mkdir -p "岚桥站0017-Godot/assets/models/props/<id>"
cp "_blout/xxx/<id>.glb" "岚桥站0017-Godot/assets/models/props/<id>/"
# 写 SOURCE.json（来源/授权/tris）

# 4) 重导入（★ 必须删 .import，否则 Godot 用缓存，白渲染好几轮）
rm -f "assets/models/props/<id>/*.import"
& $G --path . --headless --import

# 5) 在 GDScript 里用
k.model("props/<id>", Vector3(x, y, z), yaw)
# 或 floor3 那种没有 Kit 的：直接 load().instantiate() + set_meta("dynamic", true)
```

## Blender 两个隐形坑

1. **boolean 之后法线会内翻** → 导出到 Godot 后整个外壳被背面剔除，只剩零星零件悬着。
   导出前必须：`normals_make_consistent(inside=False)` + 按体积逐面校验。
2. **`create_cube(size=1.0)` 的 `size` 是边长**，按半边长传会小一半。

# 13 · 已知的坑（避免重复踩）

| 坑 | 现象 | 解法 |
|---|---|---|
| 「画了洞口」≠「洞口能过」 | 墙上画了门洞但走不过去 | **物理射线自检**，截图看不出来 |
| 同一面墙被两个函数各画一次 | 洞口被静默堵死，视觉上是两面墙叠着 | 搜同名墙面代码，或改用带洞的建墙函数 |
| 模型路径 `_1k.gltf` vs `.glb` | 自建模型加载失败、整个消失 | `LaundryKit.model()` 现在两种都找 |
| 改了 glb 但画面不变 | 渲染出来还是旧模型 | **删 `*.import` 再 `--import`** |
| GDScript 从 Array 循环推断类型 | 满屏 `Cannot infer the type` | 循环变量加显式类型：`for sx: float in [...]` |
| `var k` 不标类型 | 所有 `k.xxx()` 返回值都是 Variant | `var k: LaundryKit` |
| 变量重名 | `There is already a variable named "d"` | 大函数里插入代码前先搜同名 |
| 相机贴脸 | 渲染出来只有一块墙 | 先 `print` 出目标物的 AABB，再定机位 |
| 旧截图文件 | 改了场景但那个编号的图不变 | 确认机位确实在那个 shot 脚本里 |
